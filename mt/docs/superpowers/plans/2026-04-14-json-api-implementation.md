# JSON API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate static JSON API endpoints from Movable Type for Member site consumption, enabling centralized content logic and improved performance.

**Architecture:** Create MT Index/Archive Templates that output JSON instead of HTML. Reuse existing filter logic (`azcom-article-query-corporate`, `azcom-article-sidebar-ranking`) with JSON output wrappers. Support pagination via MT native `<mt:PagerBlock>`. Compatible with local (CF bypass) and Cloud (direct CF) environments.

**Tech Stack:** Movable Type 8.8.2, MTML templates, JSON (manual escaping via `encode_json="1"`), CustomFields (Cloud only)
